Selamat datang di randomly.id. Kami menghargai privasi kamu dan berkomitmen untuk melindunginya. Kebijakan privasi ini menjelaskan bagaimana kami mengumpulkan, menggunakan, dan melindungi informasi kamu saat menggunakan layanan kami.

1. Informasi yang Kami Kumpulkan

randomly.id tidak mengumpulkan data pribadi seperti nama, email, atau nomor telepon. Kami tidak memerlukan registrasi atau login untuk menggunakan layanan ini.

Data yang tersimpan hanya di perangkat kamu sendiri (localStorage browser), meliputi:

  • Jumlah rekomendasi yang sudah digunakan (untuk sistem token dan paywall)
  • Status cooldown
  • Preferensi pilihan kategori

Data ini tidak dikirim ke server kami dan bisa dihapus kapan saja dengan membersihkan cache browser.

2. Penggunaan AI (Claude API)

randomly.id menggunakan layanan AI dari Anthropic (Claude) untuk menghasilkan rekomendasi. Prompt yang dikirim ke API Anthropic berisi:

  • Waktu dan hari saat ini
  • Pilihan kategori dan preferensi yang kamu pilih
  • Tidak ada informasi pribadi yang dapat mengidentifikasi kamu

Data ini diproses sesuai dengan kebijakan privasi Anthropic.

3. Google AdSense & Cookies

randomly.id menggunakan Google AdSense untuk menampilkan iklan. Google AdSense menggunakan cookies untuk menampilkan iklan yang relevan berdasarkan kunjungan kamu ke situs ini dan situs lainnya.

Kamu dapat mengelola preferensi iklan atau menonaktifkan cookies melalui:

  • Google Ads Settings
  • Pengaturan browser kamu
  • aboutads.info

Untuk informasi lebih lanjut, lihat kebijakan privasi Google.

4. Log Data

Server kami (Vercel) secara otomatis mencatat informasi standar seperti alamat IP, jenis browser, dan halaman yang dikunjungi untuk keperluan keamanan dan performa. Data ini tidak digunakan untuk mengidentifikasi pengguna secara personal.

5. Layanan Pihak Ketiga

randomly.id menggunakan layanan pihak ketiga berikut:

  • Anthropic Claude API — untuk menghasilkan rekomendasi AI
  • Google AdSense — untuk menampilkan iklan
  • Vercel — untuk hosting website
  • Saweria — untuk menerima dukungan dari pengguna

Masing-masing layanan memiliki kebijakan privasi tersendiri yang berlaku untuk data yang mereka kumpulkan.

6. Keamanan Data

Kami mengambil langkah-langkah yang wajar untuk melindungi informasi kamu. Namun, tidak ada metode transmisi data melalui internet yang 100% aman. API key dan konfigurasi sensitif disimpan di server, tidak pernah terekspos ke pengguna.

7. Perubahan Kebijakan Privasi

Kami dapat memperbarui kebijakan privasi ini dari waktu ke waktu. Perubahan akan diinformasikan melalui pembaruan tanggal di bagian atas halaman ini. Kami mendorong kamu untuk meninjau halaman ini secara berkala.

8. Hak Kamu

Karena kami tidak mengumpulkan data pribadi, tidak ada data yang perlu dihapus atau diakses secara khusus. Kamu dapat menghapus data lokal kapan saja dengan membersihkan localStorage browser.
